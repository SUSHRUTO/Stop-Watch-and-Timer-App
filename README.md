# ⏱ Stopwatch & Timer App

A modern and interactive Stopwatch & Timer application built using **React**, **Vite**, and **Tailwind CSS** with a clean glassmorphism UI and responsive design.

## 🚀 Live Demo

🔗 Live Link: https://stop-watch-and-timer-app.vercel.app/


---

## 📖 Project Overview

This application provides two main utilities:

- **Stopwatch**
- **Countdown Timer**

The project focuses on accurate time handling, user interaction, clean state management, and a visually appealing user interface.

---

## ✨ Features

### ⏱ Stopwatch

- Start stopwatch
- Pause stopwatch
- Reset stopwatch
- Real-time updates
- Dynamic button state changes
- Active button glow effects
- Animated reset interaction

### ⏲ Timer

- Custom timer input
- Increase/decrease timer using controls
- Start countdown
- Pause countdown
- Reset timer
- Completion alert notification
- Real-time countdown updates

### 🎨 UI / UX Features

- Modern glassmorphism design
- Responsive layout
- Gradient background
- Interactive button animations
- Dynamic active states
- Circular timer display
- Smooth transitions

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/SUSHRUTO/Stop-Watch-and-Timer-App
```

Navigate into project directory:

```bash
cd stopwatch-timer-app
```

Install dependencies:

Using pnpm:

```bash
pnpm install
```

Start development server:

```bash
pnpm dev
```

The app will run at:

```bash
http://localhost:5173
```

---

## 🏗 Build for Production

Generate production build:

```bash
pnpm build
```

Preview production build:

```bash
pnpm preview
```
